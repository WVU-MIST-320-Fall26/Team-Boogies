## RACI Matrix

**R** = Responsible, **A** = Accountable, **C** = Consulted, **I** = Informed

| Task | Project Manager | Business Analyst | Scrum Master | Systems Architect |
|---|---|---|---|---|
| Project charter | A/R | C | C | C |
| Requirements | A | R | I | C |
| Sprint planning | I | C | A/R | C |
| System design | A | C | I | R |
| Matching algorithm | I | C | C | A/R |
| Testing | A | R | C | R |
| User acceptance testing | A | R | I | C |
| Budget and schedule | A/R | I | C | I |
| Pilot launch | A/R | C | C | R |
